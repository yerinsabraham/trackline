# Fintech Support Example

A complete example project for `trackline-gate`: retrieval, tool-selection,
multi-turn and groundedness rows, fixtures, a baseline and example harness
configs.

Use it when you want to see the scorecard before wiring trackline to your own
system:

```bash
trackline-gate init --example=fintech-support
trackline-gate run
```

For a real project, start empty instead:

```bash
trackline-gate init
```
